# 隔環ネリス

Three.js 0.186.1で動く、オリジナルの一人称シューティング。
閉鎖観測施設「折光槽」で、連射銃「灯芯九型」を使って6体の「継殻兵」を停止させます。
すべてのモデル・テクスチャ・効果音はコードで生成します。

## 遊び方

このフォルダをHTTPで配信し、ブラウザで `index.html` を開いてください。
たとえば `python -m http.server 8000` を実行して `http://localhost:8000` へアクセスします。
インストールやビルドは不要です。最初の読み込みには指定CDNへの接続が必要です。

- WASD: 移動。マウス: 視点。
- 左クリック: 射撃。押し続けると連射。
- R: リロード。弾倉18発、予備108発、リロード1.4秒。
- クリックでポインタロック。Escで解除。ロックなしでも視点と射撃を操作できます。
- 敵を全員倒すと勝ち。HPが0になると負け。「再出撃」でもう一度開始できます。

壁と遮蔽物は移動と弾を防ぎ、敵は遮蔽物を回り込んで接近します。
音はブラウザのWeb Audioで生成し、実際のクリック後に有効になります。

## 検証

`window.__game` は `tests/acceptance.md` の契約を実装しています。
`node tests/verify.mjs` でヘッドレスChromeを使ってF1〜F10と追加条件を検証できます。
検証にはNode.js 22以降とChromeが必要です。ブラウザゲーム自体にNode.jsは不要です。
Chromeの場所は `CHROME_PATH` 環境変数で指定できます。
結果は `log/acceptance-results.json`、画面は `log/game.png` などへ保存されます。

Chromeを起動できない制限環境では `node tests/simulation.mjs` で状態更新を検証できます。
これは同じ版のThree.jsと実際のゲームコードを使いますが、描画と実ブラウザのキー入力は検証しません。
