このフォルダで、ブラウザだけで動く Three.js の 3D FPS（一人称シューティング）を作ってください。ゲームの名前・敵・武器・マップ名は、既存の作品の物を使わず、全部オリジナルにしてください。画像・音の素材は、コードで作る（ジオメトリと色、必要なら canvas で描いたテクスチャ）か、著作権のない自作の物だけにしてください。外部の素材は取得しません。

## 作る物

- 壁と遮蔽物のある屋内か屋外の閉じたマップ（プレイヤーは外へ出られない）。
- 一人称視点。WASD で移動、マウスで視点、左クリックで射撃（銃）。R でリロード（弾倉の弾数と予備弾を持つ）。
- 敵 4 体以上。プレイヤーを見つけて近づき、近づいたら（または撃って）ダメージを与える。撃たれたら倒れる（`alive` が false になり、見た目でも消えるか倒れる）。
- HUD: HP、弾数、残りの敵の数、照準（クロスヘア）。
- 敵を全部倒したら「勝ち」（`status` が `won`）、HP が 0 になったら「負け」（`lost`）。画面に結果を表示する。
- クリックでポインタロックを取ってよい。ただし**ポインタロックを取れていなくても**、`document` の `mousemove` の `movementX`/`movementY` で視点が動き、マウスボタンの `mousedown` で撃てること（ロックが取れないときにテストが動かせるように）。

- `index.html` の importmap にある `three` と `three/addons/`（Three.js 0.186.1）だけを使う。**版と読み込み先を変えない。ほかのライブラリを足さない。**物理エンジンのライブラリも足さない（動きと当たり判定は自分で書く）。

- 外への通信をしない（CDN の Three.js 以外）。
