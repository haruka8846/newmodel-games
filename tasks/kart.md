このフォルダで、ブラウザだけで動く Three.js の 3D カートレースを作ってください。ゲームの名前・キャラ・コース名は、既存の作品の物を使わず、全部オリジナルにしてください。画像・音の素材は、コードで作る（ジオメトリと色、必要なら canvas で描いたテクスチャ）か、著作権のない自作の物だけにしてください。外部の素材は取得しません。

## 作る物

- 周回コース（道路、縁石か壁、地面、空）。コースの外へ出過ぎない（壁か減速帯がある）。
- プレイヤーのカート 1 台と、AI のライバル 3 台以上。3 周（`totalLaps` が 3 以上）走って順位を争う。
- 開始時にカウントダウン（3・2・1・GO）。GO の後に走れる。
- 操作: 矢印キーか WASD（上=アクセル、下=ブレーキ/後退、左右=ハンドル）。Shift か Space でドリフト（曲がりながら押すと滑って曲がりやすくなる）。
- 画面に周回数、周回タイム、順位、速度が見える（HUD）。三人称のカメラでカートを後ろから追う。
- 3 周終わったら「ゴール」の画面（`phase` が `finished`）。

## 決まり（機械テストが読む口）

`tests/acceptance.md` を読み、そこにある `window.__game` の契約どおりに作ってください。**全項目を通すこと**が完了の条件です。判定は機械で行い、見た目の良し悪しは判定しません。

- `index.html` の importmap にある `three` と `three/addons/`（Three.js 0.186.1）だけを使う。**版と読み込み先を変えない。ほかのライブラリを足さない。**物理エンジンのライブラリも足さない（動きは自分で書く）。
- ビルドの工程を足さない。`index.html` をそのまま HTTP で配って開けば動くこと。
- 外への通信をしない（CDN の Three.js 以外）。
- 作業はこのフォルダの中だけで行う。途中で質問せずに、最後まで作りきる。
- 終わったら、何を作ったかを 5 行以内で報告する。
